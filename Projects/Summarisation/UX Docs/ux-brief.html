UX Brief — ANPS Stage 3 & 5 Response Generation

📋 Acme Notice Processing System🏢 Acme Holdings📅 10 June 2026🔖 PBD v1.2

1. Background

Acme processes Penalty Charge Notice (PCN) challenges on behalf of local authorities. Today the journey from "challenge received" to "letter sent" is highly manual:

  • Notice IQ councils — agent opens Notice IQ, picks reason/sub-reason, downloads template from CRM, copies paragraphs from AIRA, pastes into letter and re-uploads
  • Third-party (Non-Notice IQ) councils — agent jumps across the council's own CRM, AIRA, evidence images and policy PDFs, manually assembling the letter

Stage 3 and Stage 5 will take structured case validation output and pre-fill the correspondence letter end-to-end, leaving the agent to review and send rather than assemble. Where AI cannot complete a letter, the case is flagged for agent intervention and QA sample-check.

2. Objectives

#Objective
O1Reduce average time to write and send a PCN response letter
O2Capture Stage 2/4 summary and bind to correct council template paragraphs
O3Two outcomes per case: Automated Complete and Action Required
O4Surface Letter Generation column so AI-complete vs. agent-needed visible at a glance
O5Route agent-amended letters into QA queue based on sampling % per agent
O6Highlight every added/deleted passage so QA reviews the diff
O7100% audit trail of validation, edits, QA decisions and send events
O8Business updates Knowledge Source and publishes within 24 hours
O9Print QR code on every outgoing letter
O10Analytics dashboard delivered with the tool
