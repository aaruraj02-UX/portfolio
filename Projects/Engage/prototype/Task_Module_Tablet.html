Annotation 4.A: Confirmation modal is dynamically populated (BR-TASK-036/037). Content changes per action type:
• Mark Complete ? Green header, shows SLA outcome, moves to Completed tab.
• Cancel Task ? Red header, warns action cannot be undone, task status becomes Cancelled.
